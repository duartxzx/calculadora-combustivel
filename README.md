# calculadora-combustivel
Primeiro projeto em Python

Se você está lendo isso, muito obrigado pela atenção, este é meu primero projeto
em python, estou começando a focar em aprender esta linguagem com intuito de transformar
tarefas repetitivas em processos ágeis. Este é um projeto bem básico mas suficiente para
meu pontapé inicial, se baseia em uma calculadora de combustível baseado no tipo que o cliente
deseja e sua respectiva litragem, o programa conta com um laço de repetição que impede o programa
de finalizar até que o usuário queira sair ou finalize uma ação através de inputs válidos
